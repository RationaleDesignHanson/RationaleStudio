Two patterns explain almost everything here

1 · Bridge blind-spot plugins. The primary automation is the cursor-talk-to-figma MCP write-bridge, driven by Claude Code. It can create and move nodes, but it can't set fonts, bind Variables/styles, batch-rename, or range-fill text. When a build hit those walls, a small plugin was written to finish the job — Route Frames, MH Social Series Helper, the Cookbook pair.

2 · Spec-to-generator plugins. Most encode a hardcoded design spec (tokens, a component list, a deck outline) and emit Figma nodes or styles in one shot — "design system as code." Several auto-run on launch, with the UI as dead or decorative code.

Provenance note: only the Socials plugin has a surviving Claude Code chat transcript on this machine. Everything else predates local history — provenance comes from git and in-repo spec markdown. No backup plugin stores a raw prompt log beside it.
